📖 Правило: общий знаменатель

Чтобы найти общий знаменатель двух дробей с большими знаменателями:

  1. Составляем дробь из знаменателей
  2. Сокращаем эту дробь до конца
  3. Записываем: изначальная дробь = сокращённая дробь
  4. Делаем бабочку (умножение крест-накрест)

Пример: 5/12 + 7/18 → 12/18 = 2/3 → 12·3 = 36, 18·2 = 36.
Доп. множители: у первой дроби 3, у второй 2 → 15/36 + 14/36 = 29/36.
