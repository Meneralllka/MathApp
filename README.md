# Котёнок идёт к маме 🐱 → 🐈

Браузерная игра для тренировки сложения и вычитания дробей с разными знаменателями.
Работает на телефоне и компьютере.

**Играть:** https://meneralllka.github.io/MathApp/

## Алгоритм, по которому решается каждый пример

Как найти общий знаменатель двух дробей с большими знаменателями:

1. Составляем дробь из знаменателей
2. Сокращаем эту дробь до конца
3. Записываем: изначальная дробь = сокращённая дробь (пропускается, если сократили сразу)
4. Делаем бабочку (умножение крест-накрест)

Дальше: доп. множители → приводим к общему знаменателю → считаем → сокращаем ответ.
Каждый верный шаг — шаг котёнка к маме, ошибка отбрасывает его назад.

## Уровни

| Уровень | Что внутри |
|---|---|
| 📒 Задачи из урока | примеры 3–7 с доски, потом похожие |
| 🌼 Тропинка у дома | сложение, знаменатели до 30 |
| 🌲 Лесная дорожка | сложение и вычитание, до 48 |
| ⛰️ Горный перевал | знаменатели до 96, ответ часто сокращается |

## Аккаунты и статистика (Firebase)

Ученик регистрируется в игре: имя, логин, PIN-код. Данные хранятся в Firestore:

- `students/{uid}` — профиль: `totals`, `levels` (звёзды), `stepStats` (верно/ошибки по каждому шагу), `errorTypes`
- `students/{uid}/errors` — каждая ошибка: пример, шаг, что ввёл, что было верно
- `students/{uid}/results` — каждый пройденный или брошенный уровень
- `students/{uid}/sessions` — каждый заход в игру

Настройка: конфиг Firebase — в начале `docs/index.html` (`FIREBASE_CONFIG`),
правила безопасности — `firestore.rules` (вставить в Firestore → Rules),
в Authentication должен быть включён вход Email/Password.

## Структура

- `docs/index.html` — вся игра (один файл, без сборки)
- `firestore.rules` — правила Firestore
- `firebase.json` — для деплоя на Firebase Hosting (`firebase deploy`), если понадобится
